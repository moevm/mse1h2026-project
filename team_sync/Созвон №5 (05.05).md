## Протокол встречи

### 1. Задачи фронтенда ()
- [ ] **Страница импорта файлов** – две формы загрузки (для студентов и для проектов).
- [ ] **Кнопка «Выбрать проект» для лидера команды**:
  - Открывается модальное окно со списком доступных проектов (не назначенных другим командам, привязанных к текущему курсу).
  - После выбора проект отображается на карточке команды.
  - Если дедлайн прошёл – кнопка становится неактивной.
- [ ] **Доделать страницу обмена проектами** – это один из самых важных пропущенных блоков.

### 2. Задачи DevOps ()
- [ ] Вернуть BuildKit для кэширования Docker-сборки (почти готово, будет в PR через 20–30 минут).
- [ ] Настроить CI для запуска тестов (включая интеграционные с поднятием тестовой базы данных) – **не критично** (заказчик снизил приоритет тестов).
- [ ] Подкорректировать текущие тесты (уже занимается).
- [ ] **LDAP** – сервис готов, нужно оттестировать корректное подключение и получение данных (через uid, name, lastname, возвращает массив).

### 3. Критичные задачи на четвёртую итерацию (обязательно сделать)
- [ ] Импорт данных (CSV/TSV) – студенты и проекты.
- [ ] Возможность выбора проекта лидером команды.
- [ ] Страница обмена проектами (рабочий обмен).

### 4. Тестовая база данных
- [ ] Подготовить дамп или seed, чтобы проверяющий (преподаватель) мог сразу запустить проект с заполненной тестовой БД и не вводить данные вручную.
### 5. Организационные моменты
- Работать оперативнее, избегать ситуации, когда всё делается в последние два дня.
- Текущая итерация – финальная, промедление недопустимо.
