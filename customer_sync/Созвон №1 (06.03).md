## Протокол встречи
В ходе встречи были рассмотрены следующие вопросы и приняты предварительные решения:
1. **Роли пользователей**:
  На текущем этапе достаточно двух ролей – студент и преподаватель. Функции админа объединяются с преподавателем (преподаватель обладает всеми правами управления).
3. **Создание проектов**:
  Необходим отдельный функционал создания проекта (не только импорт из файла). Импорт остаётся как дополнительная возможность.
4. **Формирование команд**:
  Лидер (например, магистр) может создать группу и пригласить участников.
Также доступен вариант самостоятельной записи студентов в свободные слоты команд (без обязательного приглашения).
Для курсов без выделенного лидера (например, бакалавриат) студенты могут самостоятельно формировать команды через запись в слоты.
Точный механизм будет доработан командой, с возможностью уточнения в чате.
6. **Разделение на семестры**:
  Пока разделение на семестры не реализуется. При необходимости преподаватель сможет разграничивать проекты по весеннему/осеннему семестру вручную.
7. **Docker-окружение**:
  Приложение состоит из трёх образов (Front, Back, SQL). Для демонстрации достаточно локального развёртывания. В качестве базовой ОС образов используется Ubuntu (в соответствии с существующей инфраструктурой).
