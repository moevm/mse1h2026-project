## Протокол встречи
В ходе встречи были рассмотрены следующие вопросы и приняты решения:
- **Результаты второй итерации**
  - Переход от моковых данных к реальной базе данных, подключена Prisma.
  - Реализовано управление курсами (создание, просмотр, редактирование, удаление) с разделением прав: действия доступны только администратору.
  - Добавлены health checks для мониторинга приложения (проверка связи с БД и работоспособности).
  - Настроено Docker-окружение.
  - Настроены GitHub Actions: автоматическая проверка линтера, типов, сборка проекта.
  - На фронтенде создан список курсов с разным отображением для студента и администратора. Операции сопровождаются уведомлениями об успехе или ошибке.
- **Планы на третью итерацию**
  - Реализация распределения студентов по проектам.
  - Создание страницы проектов (помимо курсов).
  - Механизм создания команд, приглашение участников.
  - Автоматическое назначение на проекты после дедлайнов.
  - Обмен проектами между командами (при наличии времени).
- **Авторизация (LDAP)**
  - Заказчик уточнил, что для работы с авторизацией необходимо разобраться с протоколом LDAP. Есть возможность развернуть локальный экземпляр LDAP в Docker, а также получить тестовые данные. Информация по настройке будет переслана команде дополнительно. Если локальное развёртывание вызовет сложности, можно запросить тестовые данные от заказчика.
- **Формат CSV для импорта/экспорта**
  - Решено, что формат импортируемых CSV-файлов должен соответствовать формату, который генерируется при экспорте. Это позволит использовать импорт/экспорт для резервного копирования и переноса данных между окружениями.
